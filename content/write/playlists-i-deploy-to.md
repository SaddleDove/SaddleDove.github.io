Shipping code is a mood. Most developers pretend it's a process — branch, test, merge, release — but it's really just anxiety with better tooling. Music is how I keep the anxiety from becoming architecture.

Here's the rotation that actually works:

## The 1975 — for the courage to be sincere

There's a version of indie rock that hides behind irony. The 1975 keep refusing to. When I have to write a README that admits what a project actually is — or worse, a changelog — I put on *Notes on a Conditional Form* and let sincerity do the heavy lifting. Deploy mood: honest.

## FKA twigs — for the strange refactor

Some refactors aren't about cleaning up, they're about seeing the code differently. *MAGDALENE* is what I play when the shape of a problem needs to break. Deploy mood: unafraid.

## Ben Howard — for the failing build

*I Forget Where We Were* is a record about staying calm in weather you can't control. When CI is red and the fix is unclear, Ben Howard is the only voice calm enough to keep me from rewriting the whole service. Deploy mood: patient.

## Perfume Genius — for the final pass

There's a tenderness in *Set My Heart on Fire Immediately* that reminds me code has users, not just consumers. The last pass before release — the one where you check the empty states and the error messages — gets Perfume Genius. Deploy mood: careful.

## Fiona Apple — for the post-mortem

When something broke in production and I have to figure out why, I need music that's willing to be furious and precise at the same time. *Fetch the Bolt Cutters* is the only album that matches the energy of reading your own logs at 2am. Deploy mood: accountable.

## The rule

Never deploy to a song you don't remember hearing. If the deploy succeeds and you can't recall what was playing, the release didn't deserve a soundtrack — and it probably didn't deserve to ship either.
